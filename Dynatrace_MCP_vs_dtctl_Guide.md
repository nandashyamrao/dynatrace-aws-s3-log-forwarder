# 🚀 Dynatrace MCP vs `dtctl`

## 🎯 Overview

-   🧠 **Dynatrace MCP** = AI-powered engineering assistant
-   🔧 **dtctl** = Deployment & automation CLI
-   ✅ Best results come from using both together.

## 🧠 Dynatrace MCP

### Best for

-   💬 Natural language
-   🔍 Troubleshooting
-   📈 Creating and explaining DQL
-   📊 Dashboard design
-   🪵 Log investigations
-   🚨 Problem analysis
-   ☸️ Kubernetes insights
-   📚 Dynatrace documentation
-   🧩 OpenPipeline design

## 🔧 dtctl

### Best for

-   🚀 Deployments
-   📦 Export/import
-   🏗️ Monaco
-   🔄 TEST → PROD promotion
-   📝 Backup
-   🌿 Git
-   ⚙️ CI/CD
-   🔁 Automation

## ⚖️ Comparison

  Capability          MCP   dtctl
  ------------------ ----- -------
  AI reasoning        ✅     ❌
  Natural language    ✅     ❌
  Generate DQL        ✅     ❌
  Troubleshoot        ✅     ❌
  Export/import       ⚠️     ✅
  Monaco              ⚠️     ✅
  CI/CD               ❌     ✅

## 💡 Workflow

1.  🧠 Think with MCP
2.  🔧 Deploy with dtctl

MCP helps you understand, design and investigate.

dtctl makes repeatable, automated changes.
